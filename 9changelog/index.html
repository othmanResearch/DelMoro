v1.0.0¶

This is the first stable main release of the DelMoro pipeline.

  • Highlights:
    • Initial production-ready implementation of the pipeline.
    • Reproducible and portable workflow built with Nextflow DSL2 (≤ v26.x).
    • Support for configurable execution through pipeline parameters and profiles.
