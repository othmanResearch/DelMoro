Pipeline Parameters¶

This section provides a comprehensive overview of all configurable parameters available in the pipeline. Each parameter can be set via the command line or a configuration file to customize the behavior of the workflow. Default values are indicated alongside a ⊕ icon, and brief descriptions are provided to help guide proper usage based on your data and analysis goals.

General Settings¶

  • --mcpus = Maximum number of CPUs available to the entire pipeline. ⊕
  • --pcpus = Number of CPUs allocated per process. ⊕
  • --outdir = Directory where all outputs will be saved. ⊕
💡 Explanation

  • If the user only specifies --pcpus, then mcpus is set equal to pcpus.
    This means the pipeline will execute tasks sequentially, using the top available CPUs per process.

  • If --mcpus is greater than 2 x pcpus, the maxForks will be set to 2, allowing up to 2 tasks to run in parallel.

Initialize my pipeline¶

  • --generate = CSV ⊕
  • --basedon = CSV to generate other input CSVs from. ⊕

Input Csv Files¶

  • --rawreads = CSV file with raw read file paths. ⊕
  • --tobetrimmed = CSV with read paths + trimming parameters. ⊕
  • --tobealigned = CSV with trimmed read paths. ⊕
  • --bam = CSV with BAM file paths. ⊕
  • --tovarcall = CSV with recalibrated BAM files. ⊕
  • --toannotate = CSV with VCF file paths. ⊕

Raw Reads Quality Check¶

  • --rawreads = CSV file with raw read file paths. ⊕

Trimming Options¶

  • --tobetrimmed = CSV with read paths + trimming parameters. ⊕
  • --trimmomatic = Enable trimming with Trimmomatic. ⊕
  • --fastp = Enable trimming with Fastp. ⊕
  • --bbduk = Enable trimming with BBDuk. ⊕
  • --adapters = Path to adapter file for trimming tools. ⊕

Indexing Reference File¶

  • --reference = Path to reference genome FASTA file. ⊕
  • --igenome = iGenomes key to download reference data. ⊕

Alignment¶

  • --reference = Path to reference genome FASTA file. ⊕
  • --tobealigned = CSV with trimmed read paths. ⊕
  • --aligner = Alignment tool to use (bwa, bwamem2, etc.). ⊕
  • --bedtarget = BED file for coverage extraction. ⊕
  • --keepinter = Keep intermediate BAM files derived from alignment. ⊕
  • --report = Enables Metrics-bigwigs-html summary for Bam files. ⊕
  • --depth = Minimum depth in coverage bin plots ⊕
  • --saveImg = Save images( plots ) from bigwig files ⊕

Base Quality Score Recalibration¶

  • --bam = CSV with BAM file paths. ⊕
  • --reference = Path to reference genome FASTA file. ⊕
  • --knownsite1 = First known variants VCF file (for BQSR). ⊕
  • --knownsite2 = Second known variants VCF file. ⊕
  • --ivcf1 = VCF resource for BQSR (downloaded). ⊕
  • --ivcf2 = Second VCF resource for BQSR. ⊕
  • --report = Enables Metrics-bigwigs-html summary for Bam files. ⊕
  • --depth = Minimum depth in coverage bin plots ⊕
  • --saveImg = Save images( plots ) from bigwig files ⊕

Variant Calling¶

  • --reference = Path to reference genome FASTA file. ⊕
  • --tovarcall = CSV with recalibrated BAM files. ⊕
  • --keepinter = Keep intermediate vcf files ⊕
  • --mode = Output type: onlyvcf to generate a vcf for each input ⊕
  • --caller = Specify deepvariant caller which also requires --modelType ⊕
  • --rsid = Add rs identifiant for vcf reference file. ⊕
  • --splitSample = Split cohort vcf to multi-samples files.⊕

Filtering¶

  • --tofilter = Path to the CSV file containing variants to filter. ⊕
  • --skipFilter = Parameter to skip filtering in fullmode. ⊕
  • --strictFilter = Parameter to enable strict filter ( gatk & AB based filters ). ⊕
  • --gatkFilter = Parameter to enable only GATK filters. ⊕
  • --QD = Quality by Depth: variant confidence normalized by depth. ⊕
  • --QUAL = Overall variant quality score. ⊕
  • --SOR = Strand Odds Ratio: measures strand bias. ⊕
  • --FSSNP = Fisher Strand p-value for strand bias (SNPs). ⊕
  • --MQ = RMS Mapping Quality of reads supporting the variant. ⊕
  • --MQRankSum = Z-score from Wilcoxon rank sum test of Alt vs Ref read mapping qualities. ⊕
  • --ReadPosRankSumSNP = Z-score from Wilcoxon rank sum test of Alt vs Ref read position within reads (SNPs). ⊕
  • --FSINDEL = Fisher Strand p-value for strand bias (INDELs). ⊕
  • --ReadPosRankSumINDEL = Z-score from Wilcoxon rank sum test of Alt vs Ref read position within reads (INDELs). ⊕
  • --GQ = Minimum genotype quality threshold. ⊕
  • --DP = Minimum read depth threshold. ⊕
  • --ABmin = Minimum allele balance threshold. ⊕
  • --ABmax = Maximum allele balance threshold. ⊕

Annotation (VEP)¶

  • --species = Species name for VEP cache. ⊕
  • --cachetype = VEP cache type (refseq or merged). ⊕
  • --assembly = Genome assembly version. ⊕
  • --cachedir = Path to VEP cache directory. ⊕

Reporting¶

  • --metaPatients = Csv of patiens' Metadata + bam paths + vcf paths ⊕
  • --metaYaml = Yaml file of Physician metadata + executions steps info ⊕
