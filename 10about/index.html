About¶

This documentation provides an overview of the DelMoro pipeline, including its purpose, architecture, workflow, configuration and execution requirements. Supported by Docker, Singularity, Wave, and Conda environments, DelMoro ensures easy deployment across diverse systems. With an option of integrating a graphical user interface built with PyQt, allowing users to configure and run analyses without requiring command-line expertise.
